# Curso de MySQL - *Curso em Vídeo*

Repositório com os scripts, exercícios e anotações desenvolvidos durante o curso de MySQL do Professor Gustavo Guanabara, focado nos fundamentos da linguagem SQL e no gerenciamento de bancos de dados relacionais.

## Conteúdos Abordados

- Introdução ao Modelo Relacional e Diagrama Entidade-Relacionamento (DER)
- Linguagem de Definição de Dados (DDL)
- Linguagem de Manipulação de Dados (DML)
- Linguagem de Consulta de Dados (DQL)
- Chaves Primárias (PK) e Estrangeiras (FK)
- Junção de Tabelas
- Gerenciamento do Banco de Dados
